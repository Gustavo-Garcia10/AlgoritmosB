# Algoritmos e Programação B

Exercícios da disciplina de Algoritmos e Programação, feitos em C e C++.

Os programas estão na pasta [programas](programas), que tem um README com a descrição de cada um.

O que foi visto em cada aula, com os programas de cada conteúdo, está nas [notas de aula](notas-de-aula.md).

## Conteúdo

- Menus com `switch` e cadastros usando `struct` e `vector`
- Vetores: números aleatórios, ordenação, média, mediana, maior e menor elemento
- Funções com passagem de parâmetro por valor e por referência
- Manipulação de strings
- Leitura e escrita de arquivos de texto

## Como compilar

```bash
g++ programas/academia_aluno_mais_alto.cpp -o academia
./academia
```
